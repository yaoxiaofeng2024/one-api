## 1.1 项目介绍

### One-API 是什么？

One-API 是一个开源的 LLM（大语言模型）API 管理和分发系统。它的核心价值在于：

1. **统一接口**：将不同厂商的 AI API（OpenAI、Claude、Gemini、文心一言等）统一为标准 OpenAI 格式
2. **密钥管理**：集中管理多个渠道的 API Key，避免分散配置
3. **负载均衡**：智能分配请求到多个渠道，提高可用性
4. **用量统计**：详细记录每个用户、每个模型的调用情况
5. **额度控制**：支持配额管理、令牌过期、IP 限制等功能

### 核心功能概览

✅ 支持 30+ AI 模型提供商：
- OpenAI ChatGPT 系列（含 Azure）
- Anthropic Claude 系列
- Google Gemini/PaLM 系列
- 百度文心一言、阿里通义千问、讯飞星火、智谱 ChatGLM
- DeepSeek、Moonshot、字节豆包
- ...以及更多

✅ 企业级特性：
- 多用户管理系统
- API Token 管理
- 渠道负载均衡
- 失败自动重试
- 流式响应支持
- 详细的日志和统计

### 应用场景

1. **企业内部 AI 平台**：统一管理多个 AI 供应商，降低采购成本
2. **SaaS 服务集成**：为多个客户提供 AI 能力，按用量计费
3. **开发测试环境**：快速切换不同模型进行对比测试
4. **个人开发者**：整合多个免费/低价渠道，降低成本

### 安装步骤

#### Step 1: 安装 Go 语言环境（Windows）

1. 访问 https://go.dev/dl/
2. 下载 `go1.21.x.windows-amd64.msi` 安装包
3. 双击运行安装程序，使用默认设置即可
   - 默认安装路径：`C:\Go`
   - 会自动配置环境变量
4. 安装完成后，打开 PowerShell 验证：
```powershell
go version
# 输出示例：go version go1.21.6 windows/amd64
```

**如果 `go version` 命令找不到：**
1. 右键"此电脑" → "属性" → "高级系统设置"
2. 点击"环境变量"
3. 在"系统变量"中找到 `Path`
4. 确保包含 `C:\Go\bin`
5. 重新打开 PowerShell 再次尝试

#### Step 2: 安装 Node.js（Windows）

1. 访问 https://nodejs.org/
2. 下载 **LTS 版本**（推荐 18.x 或 20.x）的 Windows 安装包（.msi）
3. 双击运行，全部使用默认选项即可
4. 安装完成后，打开 PowerShell 验证：
```powershell
node --version
# 输出示例：v20.10.0

npm --version
# 输出示例：10.2.3
```

#### Step 3: 安装 MySQL（Windows）

1. **下载 MySQL**
   - 访问：https://dev.mysql.com/downloads/mysql/
   - 选择 Windows 版本，下载 MSI 安装包
   - 选择 "MySQL Installer for Windows"

2. **安装步骤**
   - 双击运行安装程序
   - 选择 **"Server only"** 或 **"Custom"**（推荐 Custom，只安装 Server 和 Command Line）
   - 类型选择 **"Standalone MySQL Server"**
   - 配置类型选择 **"Development Computer"**
   - 端口保持默认 **3306**
   - 认证方法选择 **"Use Legacy Authentication Method"**（兼容性更好）
   - 设置 root 密码（本教程使用 `123456`，生产环境请使用强密码）
   - 点击 **"Execute"** 执行安装

3. **验证安装**

   **重要：关闭所有 PowerShell 窗口，重新打开一个新的！**

   ```powershell
   mysql --version
   # 应该输出：mysql  Ver 8.0.xx for Win64 on x86_64
   ```

4. **测试连接**
   ```powershell
   mysql -u root -p123456 -e "SELECT VERSION();"
   # 应该输出 MySQL 版本号
   ```

5. **如果 mysql 命令找不到**
   ```powershell
   # 手动添加环境变量（路径根据实际安装位置调整）：
   [Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Program Files\MySQL\MySQL Server 8.0\bin", [EnvironmentVariableTarget]::User)
   # 重新打开 PowerShell 后再次验证
   ```

6. **手动创建数据库（⚠️ 启动 One-API 前必须执行！）**
   ```powershell
   # 登录 MySQL
   mysql -u root -p123456

   # 在 MySQL 命令行中执行：
   CREATE DATABASE IF NOT EXISTS `one-api` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   SHOW DATABASES;
   # 应该能看到 one-api 数据库
   EXIT;
   ```

   > **重要说明：** One-API 启动时会通过 GORM 的 `AutoMigrate` 自动创建所有表（users、tokens、channels 等），但**数据库本身需要手动创建**。如果忘记创建数据库，启动时会报错 `Unknown database 'one-api'`。

#### Step 4: 安装 Redis（Windows）

1. **下载 Redis for Windows**
   - 访问：https://github.com/tporadowski/redis/releases
   - 下载最新版 `Redis-x64-*.msi` 安装包

2. **安装步骤**
   - 双击运行安装程序
   - 勾选 **"Add Redis to PATH"**（添加到环境变量）
   - 端口保持默认 **6379**
   - 勾选 **"Install as Windows Service"**（安装为 Windows 服务，开机自启）
   - 点击 **"Install"**

3. **验证安装**
   ```powershell
   redis-server --version
   # 应该输出：Redis server v=7.0.xx

   redis-cli ping
   # 应该输出：PONG
   ```

4. **Redis 常用管理命令**
   ```powershell
   net start Redis     # 启动服务
   net stop Redis      # 停止服务
   redis-cli           # 进入 Redis CLI
   ```

#### Step 5: 克隆项目代码

```powershell
cd D:\codes
git clone https://github.com/songquanpeng/one-api.git
cd one-api
```

**如果 Git 克隆速度慢，使用国内镜像：**
```powershell
git clone https://ghproxy.com/https://github.com/songquanpeng/one-api.git
```

#### Step 6: 下载 Go 依赖

```powershell
cd D:\codes\one-api

# 配置国内代理（加速依赖下载）
go env -w GOPROXY=https://goproxy.cn,direct

# 下载所有依赖
go mod download
```

## 1.3 配置 MySQL 与 Redis 连接

### 创建 `.env` 配置文件

在项目根目录 `D:\codes\one-api` 创建 `.env` 文件：

```ini
# ========== 服务端口 ==========
PORT=3000

# ========== MySQL 数据库配置 ==========
# 格式：用户名:密码@tcp(主机:端口)/数据库名?参数
SQL_DSN=root:123456@tcp(localhost:3306)/one-api?charset=utf8mb4&parseTime=True&loc=Local

# 日志数据库（可选，不设置则与主库共用）
# LOG_SQL_DSN=root:123456@tcp(localhost:3306)/one-api-log?charset=utf8mb4&parseTime=True&loc=Local

# ========== Redis 配置 ==========
REDIS_CONN_STRING=redis://127.0.0.1:6379/0

# ⚠️ 内存缓存同步频率（秒），启用 Redis 时必须设置此值，否则 Redis 不会生效！
SYNC_FREQUENCY=60

# ========== 会话安全 ==========
# 会话密钥（生产环境务必修改为随机字符串）
# SESSION_SECRET=your_random_secret_key
```

**生成随机 SESSION_SECRET（生产环境推荐）：**

```powershell
# 生成 32 位随机字符串
$secret = [Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Minimum 0 -Maximum 256 }))
Write-Host "生成的 SESSION_SECRET: $secret"

# 直接更新到 .env 文件
(Get-Content .env) -replace 'SESSION_SECRET=.*', "SESSION_SECRET=$secret" | Set-Content .env
```

## 1.4 构建前端

> **重要：** One-API 的 Go 后端通过 `//go:embed web/build/*` 指令将前端静态文件编译进二进制。如果 `web/build/` 目录为空，启动后访问 `http://localhost:3000` 会看到**空白页面**！

### 前端构建步骤

```powershell
# 1. 进入前端目录
cd D:\codes\one-api\web\default

# 2. 切换 npm 镜像源（国内加速，从超时变为 55 秒内完成）
npm config set registry https://registry.npmmirror.com

# 3. 安装前端依赖
npm install

# 4. 构建前端（⚠️ Windows 兼容性问题，见下方说明）
npx react-scripts build

# 5. 将构建产物移动到 Go 后端期望的位置
#    原始构建脚本使用了 rm/mv 命令，Windows 不兼容，需手动操作：
if (Test-Path "..\build\default") { Remove-Item -Recurse -Force "..\build\default" }
New-Item -ItemType Directory -Path "..\build" -Force | Out-Null
Move-Item -Path "build" -Destination "..\build\default"

# 6. 返回项目根目录
cd D:\codes\one-api
```

### Windows 构建踩坑总结

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `npm install` 超时/极慢 | 默认使用国外 npm 源 | `npm config set registry https://registry.npmmirror.com` |
| `npm run build` 报错 `'rm' is not recognized` | `package.json` 中构建脚本使用了 Unix 命令 | 改用 `npx react-scripts build` + 手动移动目录 |
| 启动后页面空白 | `web/build/` 目录为空，Go embed 无内容 | 先构建前端，再编译/运行 Go 后端 |
| `go build` 后仍空白 | 构建前端后未重新编译 Go | 前端有变动后必须重新 `go build` |

### 构建脚本 Windows 兼容修复（可选，一劳永逸）

修改 `web/default/package.json` 中的 `build` 脚本：

```json
// 修改前（仅 Linux/Mac 可用）：
"build": "react-scripts build && rm -rf ../build/default && mv -f build ../build/default"

// 修改后（跨平台兼容）：
"build": "react-scripts build && rimraf ../build/default && cpr build ../build/default"
```

需要安装跨平台工具：
```powershell
npm install --save-dev rimraf cpr
```

修改后就可以直接使用 `npm run build` 了。

## 1.5 启动服务

### 启动前检查

```powershell
# 1. MySQL 正在运行且数据库已创建
mysql -u root -p123456 -e "SHOW DATABASES LIKE 'one-api';"

# 2. Redis 正在运行
redis-cli ping
# 应该输出：PONG

# 3. .env 配置文件存在
Test-Path .env
# 应该输出：True
```

### 启动方式一：一体启动（推荐日常使用）

前后端集成在一个进程中，只需启动一个程序：

```powershell
cd D:\codes\one-api
go run main.go
```

**预期输出：**
```
One API v0.6.0 started
using MySQL as database
database migration started
database migrated
Redis is enabled
root account created
server started on http://localhost:3000
```

浏览器访问 `http://localhost:3000`，前端页面和后端 API 都由同一个进程提供。

### 启动方式二：前后端分离启动（推荐前端开发）

频繁修改前端代码时，用开发服务器可以热更新：

| 进程 | 命令 | 端口 | 说明 |
|------|------|------|------|
| Go 后端 | `go run .` 或 `.\one-api.exe` | 3000 | 提供 API 服务 |
| React 前端 | `cd web/default && npm start` | 3001 | 热更新开发服务器 |

```powershell
# 终端 1：启动 Go 后端
cd D:\codes\one-api
go run main.go

# 终端 2：启动前端开发服务器
cd D:\codes\one-api\web\default
npm start
```

> **注意：** `package.json` 中已配置 `"proxy": "http://localhost:3000"`，前端开发服务器会自动将 API 请求转发到 Go 后端。浏览器访问 `http://localhost:3001` 即可。

### 启动方式三：编译后运行（推荐生产环境）

```powershell
cd D:\codes\one-api

# 编译（生成 one-api.exe）
go build -ldflags "-s -w" -o one-api.exe

# 运行
.\one-api.exe --port 3000
```

**编译后的优势：**
- ✅ 无需 Go 环境即可运行
- ✅ 启动速度更快
- ✅ 可以分发给其他人使用

### 启动模式选择指南

| 场景 | 推荐模式 | 原因 |
|------|----------|------|
| 改完了要测试/部署 | 一体启动 | 只跑一个进程，最方便 |
| 正在开发前端代码 | 分离启动 | 热更新，改完即生效 |
| 只改后端代码 | 一体启动 | 无需重新构建前端 |
| 前后端都改了 | 分离启动 | 前端热更新 + 后端 `go run` |

### 启动常见问题

| 报错信息 | 原因 | 解决 |
|----------|------|------|
| `Unknown database 'one-api'` | 未创建数据库 | 执行 1.2 节 Step 3 中的建库 SQL |
| `Access denied for user 'root'@'localhost'` | MySQL 密码不正确 | 检查 `.env` 中的 `SQL_DSN` |
| `REDIS_CONN_STRING not set, Redis is not enabled` | .env 文件未正确加载 | 确认文件在项目根目录 |
| `SYNC_FREQUENCY not set, Redis is disabled` | 缺少同步频率配置 | 在 `.env` 中添加 `SYNC_FREQUENCY=60` |
| 页面空白 | 未构建前端 | 参见 1.4 节构建前端 |
| 端口占用 | 3000 端口被其他程序使用 | `netstat -ano \| findstr :3000` 查看并关闭 |

## 1.6 配置文件详解

### 环境变量完整参考

One-API 通过环境变量进行配置，支持两种方式：
1. 创建 `.env` 文件（推荐）
2. 直接设置系统环境变量

##### 核心配置项

**MySQL 数据库配置：**
```bash
# MySQL 连接字符串（DSN 格式）
SQL_DSN="root:123456@tcp(localhost:3306)/one-api?charset=utf8mb4&parseTime=True&loc=Local"

# 日志数据库（可选）
LOG_SQL_DSN="root:123456@tcp(localhost:3306)/one-api-log?charset=utf8mb4&parseTime=True&loc=Local"

# 数据库连接池配置
SQL_MAX_IDLE_CONNS=100   # 最大空闲连接数
SQL_MAX_OPEN_CONNS=1000  # 最大打开连接数
```

**Redis 配置（必需）：**
```bash
REDIS_CONN_STRING="redis://127.0.0.1:6379/0"
# 如果 Redis 有密码：
# REDIS_CONN_STRING="redis://:your_password@127.0.0.1:6379/0"
# ⚠️ 必须设置 SYNC_FREQUENCY，否则 Redis 不会生效！
SYNC_FREQUENCY=60
```

**Session 配置：**
```bash
# Session 加密密钥（生产环境必须设置，否则每次重启会话都会失效）
SESSION_SECRET="your-random-secret-key-here"
```

**其他配置：**
```bash
PORT=3000                  # 端口号
TZ=Asia/Shanghai           # 时区
DEBUG=true                 # 调试模式
LOG_DIR=./logs             # 日志目录
THEME=default              # 主题名称
CHANNEL_TEST_FREQUENCY=300 # 渠道自动测试频率（秒）
BATCH_UPDATE_ENABLED=true  # 批量更新模式（高并发场景）
```

**节点配置（多机部署）：**
```bash
NODE_TYPE="master"                    # master 或 slave
FRONTEND_BASE_URL="https://api.yourdomain.com"  # 从节点前端地址
```

### 配置优先级

```
.env 文件 < 系统环境变量 < 命令行参数
```

**示例：**
```powershell
# .env 中 PORT=3000
# 但命令行指定 --port 8080
.\one-api.exe --port 8080  # 最终使用 8080
```

**临时设置环境变量（仅当前会话）：**
```powershell
$env:SESSION_SECRET="your-secret-key"
$env:PORT="8080"
go run main.go
```
