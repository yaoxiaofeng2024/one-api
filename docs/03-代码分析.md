### 核心模块职责

| 模块 | 职责 | 关键文件 |
|------|------|----------|
| **Router** | 路由分发，将请求导向正确的处理器 | `router/*.go` |
| **Middleware** | 横切关注点（认证、限流、日志等） | `middleware/*.go` |
| **Controller** | 业务逻辑处理，协调 Model 和 Relay | `controller/*.go` |
| **Model** | 数据持久化，数据库 CRUD + 缓存 | `model/*.go` |
| **Relay** | 核心转发，适配不同厂商 API | `relay/**/*.go` |
| **Common** | 通用工具，配置、日志、辅助函数 | `common/**/*.go` |

### 数据流向示例：用户调用聊天接口

```
1. 用户发送 POST /v1/chat/completions（携带 Bearer Token）
   ↓
2. Router 匹配到 relay.go 中的路由
   ↓
3. 经过中间件链：
   - TokenAuth() 验证 API Key
   - RateLimit() 检查限流
   ↓
4. Controller.relayChatCompletions() 接收请求
   ↓
5. Relay 层处理：
   a. 解析 Token，获取用户信息
   b. 根据模型名称选择合适的 Channel（负载均衡）
   c. 获取对应的 Adaptor（如 OpenAI Adaptor）
   d. 转换请求格式为目标厂商格式
   e. 发起 HTTP 请求到第三方 API
   f. 接收响应并转换为 OpenAI 标准格式
   g. 计算 Token 消耗，扣除配额
   h. 记录调用日志
   ↓
6. 返回响应给用户
```

## 3.2 启动流程分析

### main.go 完整解析

```go
package main

import (
    // ... 导入依赖
)

//go:embed web/build/*
var buildFS embed.FS  // 嵌入前端静态文件

func main() {
    // Step 1: 初始化通用配置（加载 .env、读取环境变量、设置时区）
    common.Init()

    // Step 2: 设置日志系统（创建日志目录、配置日志级别）
    logger.SetupLogger()
    logger.SysLogf("One API %s started", common.Version)

    // Step 3: 设置 Gin 模式（非 DebugMode 则设为 ReleaseMode）
    if os.Getenv("GIN_MODE") != gin.DebugMode {
        gin.SetMode(gin.ReleaseMode)
    }

    // Step 4: 初始化数据库（根据 SQL_DSN 选择 MySQL/PostgreSQL/SQLite，执行 AutoMigrate）
    model.InitDB()
    model.InitLogDB()

    // Step 5: 创建默认管理员账号（首次启动时创建 root/123456）
    err = model.CreateRootAccountIfNeed()
    if err != nil {
        logger.FatalLog("database init error: " + err.Error())
    }

    // Step 6: 延迟关闭数据库连接
    defer func() {
        err := model.CloseDB()
        if err != nil {
            logger.FatalLog("failed to close database: " + err.Error())
        }
    }()

    // Step 7: 初始化 Redis（如果配置了 REDIS_CONN_STRING + SYNC_FREQUENCY）
    err = common.InitRedisClient()
    if err != nil {
        logger.SysError("init redis client failed: " + err.Error())
    }

    // Step 8: 初始化 HTTP 客户端
    client.InitHTTPClient()

    // Step 9: 注册路由（API、Web、Relay 三类路由）
    router.SetRouter(buildFS)

    // Step 10: 启动 HTTP 服务器
    err = server.Run()
    if err != nil {
        logger.FatalLog(err.Error())
    }
}
```

### common.Init() 初始化内容

- 加载 `.env` 文件（如果存在）
- 读取命令行参数（`--port`、`--version`、`--log-dir`）
- 初始化配置常量（端口、数据库 DSN、Redis 连接串等）
- 处理 `SESSION_SECRET` 环境变量
- 创建日志目录

## 3.3 路由系统

### 三类路由

**1. API 路由** (`router/api.go`) - `/api/*` — 管理后台前后端交互接口

```go
func SetApiRouter(router *gin.Engine) {
    apiRouter := router.Group("/api")
    apiRouter.Use(gzip.Gzip(gzip.DefaultCompression))
    apiRouter.Use(middleware.GlobalAPIRateLimit())
    {
        // 公开接口（无需认证）
        apiRouter.GET("/status", controller.GetStatus)
        apiRouter.GET("/notice", controller.GetNotice)

        // 用户认证接口
        userRoute := apiRouter.Group("/user")
        userRoute.POST("/register", ..., controller.Register)
        userRoute.POST("/login", ..., controller.Login)

        // 需要登录的接口
        selfRoute := userRoute.Group("/")
        selfRoute.Use(middleware.UserAuth())
        selfRoute.GET("/self", controller.GetSelf)

        // 需要管理员权限的接口
        adminRoute := userRoute.Group("/")
        adminRoute.Use(middleware.AdminAuth())
        adminRoute.GET("/", controller.GetAllUsers)

        // 渠道管理（仅管理员）
        channelRoute := apiRouter.Group("/channel")
        channelRoute.Use(middleware.AdminAuth())
        channelRoute.GET("/", controller.GetAllChannels)
        channelRoute.POST("/", controller.AddChannel)

        // Token 管理（普通用户）
        tokenRoute := apiRouter.Group("/token")
        tokenRoute.Use(middleware.UserAuth())
        tokenRoute.GET("/", controller.GetAllTokens)
        tokenRoute.POST("/", controller.AddToken)
    }
}
```

**2. Web 路由** (`router/web.go`) - `/` — 前端页面和静态资源

```go
func SetWebRouter(router *gin.Engine, buildFS embed.FS) {
    // SPA 单页应用，所有未匹配路由返回 index.html
    router.NoRoute(func(c *gin.Context) {
        c.FileFromFS("/", http.FS(buildFS))
    })
    router.StaticFS("/public", http.FS(buildFS))
}
```

**3. Relay 路由** (`router/relay.go`) - `/v1/*` — 核心转发接口

```go
func SetRelayRouter(router *gin.Engine) {
    v1Router := router.Group("/v1")
    v1Router.Use(middleware.TokenAuth())  // Token 认证
    {
        v1Router.POST("/chat/completions", controller.RelayChatCompletions)
        v1Router.POST("/completions", controller.RelayCompletions)
        v1Router.POST("/images/generations", controller.RelayImageGeneration)
        v1Router.POST("/audio/speech", controller.RelayAudioSpeech)
        v1Router.GET("/models", controller.RelayModels)
    }
}
```

## 3.4 中间件链

### 中间件执行顺序

```
Request → Recovery → Logger → CORS → RateLimit → Auth → Handler → Response
```

### 认证中间件 (`middleware/auth.go`)

**四种认证级别：**

```go
// 用户认证（需要登录，基于 Session）
func UserAuth() gin.HandlerFunc

// 管理员认证（需要 role >= 10）
func AdminAuth() gin.HandlerFunc

// Root 超级管理员认证（需要 role == 100）
func RootAuth() gin.HandlerFunc

// Token 认证（API 调用，基于 Bearer Token）
func TokenAuth() gin.HandlerFunc
```

**TokenAuth 认证流程：**
1. 从 `Authorization: Bearer sk-xxx` 提取 Token
2. 调用 `model.ValidateUserToken()` 验证有效性
3. 检查 Token 状态（是否禁用）
4. 检查 Token 额度（是否耗尽）
5. 将 `userId`、`tokenId` 写入 Gin Context

### 限流中间件 (`middleware/rate-limit.go`)

```go
// 全局 API 限流：60 次/秒
var globalApiRateLimit = rate.NewLimiter(rate.Every(time.Second), 60)

// 关键操作限流：5 次/分钟（注册、重置密码等）
var criticalRateLimit = rate.NewLimiter(rate.Every(time.Minute), 5)
```

### 其他中间件

| 中间件 | 文件 | 功能 |
|--------|------|------|
| CORS | `cors.go` | 跨域资源共享，允许所有来源 |
| Logger | `logger.go` | 请求日志记录 |
| Recover | `recover.go` | panic 恢复，防止服务崩溃 |
| Distributor | `distributor.go` | 请求分发，选择渠道 |
| Gzip | `gzip.go` | 响应 Gzip 压缩 |

### 数据库初始化流程 (`model/main.go`)

```go
func InitDB() (err error) {
    // Step 1: 根据 SQL_DSN 判断数据库类型
    if sqlDSN == "" {
        dbType = "sqlite"        // 无 SQL_DSN 时使用 SQLite
    } else if strings.HasPrefix(sqlDSN, "postgres://") {
        dbType = "postgres"
    } else {
        dbType = "mysql"         // 默认 MySQL
    }

    // Step 2: 创建数据库连接
    switch dbType {
    case "mysql":
        db, err = gorm.Open(mysql.Open(sqlDSN), &gorm.Config{
            DisableForeignKeyConstraintWhenMigrating: true,
        })
    // ... sqlite, postgres ...
    }

    // Step 3: 配置连接池
    sqlDB.SetMaxIdleConns(10)
    sqlDB.SetMaxOpenConns(100)
    sqlDB.SetConnMaxLifetime(time.Hour)

    // Step 4: 自动迁移表结构（AutoMigrate 只添加字段，不删除）
    db.AutoMigrate(&User{}, &Token{}, &Channel{}, &Ability{}, &Redemption{}, &Log{}, &Option{})

    // Step 5: 创建索引
    createIndex()
}
```

### GORM 使用示例

type User struct {

// BeforeCreate Hook：创建前自动哈希密码
func (user *User) BeforeCreate(tx *gorm.DB) error {
    hash, _ := bcrypt.GenerateFromPassword([]byte(user.Password), bcrypt.DefaultCost)
    user.Password = string(hash)
    return nil

### Redis 缓存机制

**缓存内容与 TTL：**

| 缓存项 | 前缀 | TTL |
|--------|------|-----|
| 渠道信息 | `channel:` | 10 分钟 |
| 用户信息 | `user:` | 5 分钟 |
| Token 验证 | `token:` | 3 分钟 |
| 系统配置 | `option:` | 15 分钟 |

**缓存一致性策略：**
1. **失效策略**：更新数据库后删除缓存，下次读取时重新加载
2. **TTL 兜底**：即使不一致，也会在几分钟后自动恢复

**缓存操作示例：**
```go
// 获取渠道缓存（先查 Redis，未命中查 MySQL 并回写）
func GetChannelCache(id int) (*Channel, error) {
    key := fmt.Sprintf("channel:%d", id)
    data, err := RDB.Get(ctx, key).Result()
    if err == nil {
        // 缓存命中
        var channel Channel
        json.Unmarshal([]byte(data), &channel)
        return &channel, nil
    }
    // 缓存未命中，查数据库
    channel, _ := GetChannelById(id, false)
    data, _ = json.Marshal(channel)
    RDB.Set(ctx, key, data, 10*time.Minute)
    return channel, nil
}
```

### 适配器模式

每个渠道对应一个 Adaptor，负责请求/响应格式转换：

```go
type Adaptor interface {
    Init(meta *meta.Meta)                      // 初始化元数据
    GetRequestURL(meta *meta.Meta) string      // 获取请求 URL
    SetupRequestHeader(c *gin.Context, ...)    // 设置请求头
    ConvertRequest(c *gin.Context, ...)        // 转换请求格式
    DoResponse(c *gin.Context, ...)            // 处理响应
}
```

**工作流程：**
1. 根据渠道类型获取对应 Adaptor
2. Adaptor 将标准 OpenAI 格式请求转换为目标厂商格式
3. 发送 HTTP 请求到目标厂商 API
4. Adaptor 将目标厂商响应转换回 OpenAI 标准格式
5. 返回给用户
